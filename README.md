# audio-tours

GPS-triggered driving audio tours: a static, offline-capable web player on GitHub Pages,
with narration and sound generated by ElevenLabs.

- Player: `site/player/` and `site/sw.js` (no build step), shared by every tour. Each tour is
  `site/<tour>/`, e.g. https://electronjoe.github.io/audio-tours/hobart/ (`?sim=20` adds a
  simulated drive). `tour publish` generates everything else under `site/`: `tour.json`, the
  audio, and the page, manifest and tour list from the templates in `site/player/`.
  `tour map` writes `site/<tour>/map.json`, the base map, from OpenStreetMap: those files are
  © OpenStreetMap contributors, under the [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- Tours: `tours/<tour>/`: `tour.toml` (`[tour]` title, voice, SFX, mastering, stops),
  `source/working-draft.md` (narration, one `## Script:` section per stop), `plan.md`
- Pipeline: `src/audiotour/` (CLI: `uv run tour --help`), copied from the audiobooks repo
- `docs/tech-stack.md`: what the pipeline and player are built with
- `docs/tour-json.md`: the `tour.json` format the player reads
- `docs/process/`: how to make a tour (route, stops, research, topics, scripts, sound)
- `tasks/`: work items, one Markdown file each

## Setup

```sh
uv sync
cp .env.example .env   # add ELEVENLABS_API_KEY
uv run tour account    # free: credits remaining
```

## Making a tour

Hobart is the test tour (test-only since 2026-11-02): the commands below use it, and the tests
drive it, but new content goes into a new tour (`uv run tour new <slug>`).

```sh
uv run tour new bruny --title "Hobart to Bruny Island"   # offline: tours/bruny/ from docs/process/templates/
uv run tour route hobart --out /tmp/route.json   # free (OSRM, cached): legs from [route.*], leg table
uv run tour plan-check hobart            # offline: triggers on the route, road time, radii, strict
uv run tour map hobart                   # free (OpenStreetMap, cached): site/hobart/map.json, the base map
uv run tour check hobart                 # free: draft follows the format in docs/process/5-scripts.md; song links checked with Spotify
uv run tour design hobart --name ... --description ... --text ...   # PAID: voice previews
uv run tour sfx hobart                   # PAID: chime and effects from tour.toml
uv run tour render hobart stop-1         # PAID: narration (max 3 at once on this plan)
uv run tour master hobart stop-1         # offline: chime + narration, loudness-normalised
uv run tour publish hobart               # offline: site/hobart/ (tour.json, hashed audio, page) + tour list
uv run tour pages                        # offline: rewrite every tour's page after editing site/player/ templates
uv run pytest                            # pipeline tests
uv run --with playwright python tests/player_drive.py hobart   # simulated drive in headless Chrome
```

Pushing `site/` to `main` deploys Pages (`.github/workflows/pages.yml`).

## How the player triggers

Stops play in sequence. Only the next unplayed stop, or the one after it, can be triggered by
GPS (a `strict` stop waits for the one before it), so a return-leg story at the same place as
an outbound one stays silent on the way out. A triggered stop queues behind the one playing and
never interrupts it. "Play it now" (the car screen, for the next story) and "Play now" (a story in
All stories, or a pin's card on the map) override GPS.
