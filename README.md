# audio-tours

GPS-triggered driving audio tours: a static, offline-capable web player on GitHub Pages,
with narration and sound generated by ElevenLabs.

- Player: `site/` (no build step). Each tour is `site/<tour>/`, e.g.
  https://electronjoe.github.io/audio-tours/hobart/ (`?sim=20` adds a simulated drive)
- Tours: `tours/<tour>/`: `tour.toml` (voice, SFX, mastering, stop coordinates),
  `source/working-draft.md` (narration, one `## Script:` section per stop), `plan.md`
- Pipeline: `src/audiotour/` (CLI: `uv run tour --help`), copied from the audiobooks repo
- `docs/script-format.md`: the narration contract

## Setup

```sh
uv sync
cp .env.example .env   # add ELEVENLABS_API_KEY
uv run tour account    # free: credits remaining
```

## Making a tour

```sh
uv run tour check hobart                 # offline: draft follows docs/script-format.md
uv run tour design hobart --name ... --description ... --text ...   # PAID: voice previews
uv run tour sfx hobart                   # PAID: chime and effects from tour.toml
uv run tour render hobart stop-1         # PAID: narration (max 3 at once on this plan)
uv run tour master hobart stop-1         # offline: chime + narration, loudness-normalised
uv run tour publish hobart               # offline: site/hobart/tour.json + hashed audio
uv run pytest                            # pipeline tests
uv run --with playwright python tests/player_drive.py hobart   # simulated drive in headless Chrome
```

Pushing `site/` to `main` deploys Pages (`.github/workflows/pages.yml`).

## How the player triggers

Stops play in sequence. Only the next unplayed stop, or the one after it, can be triggered by
GPS (a `strict` stop waits for the one before it), so a return-leg story at the same place as
an outbound one stays silent on the way out. A triggered stop queues behind the one playing and
never interrupts it. "Start here" (tap a stop) and "Play now" (Next stop card) override GPS.
