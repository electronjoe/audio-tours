GPS background probe

A throwaway lab page: it logs every location fix and tells us whether Chrome keeps delivering them while this page is hidden or the screen is locked. The log stays on this phone until you copy or share it. The screen never shows your coordinates.

Test phase (tap at the start of each step)

Test plan (Android Chrome)

Do this as a passenger in a moving car, or on a walk outside, so the GPS has something to report. Close the tour tab first. If Chrome asks for location, allow it. Leave the phone's volume at a normal level.

  1. 1 Screen on: tap Start GPS, then 1 Screen on. Keep this page in front with the screen on for 2 minutes.
  2. 2 Spotify: tap 2 Spotify, open Spotify and play a song for 3 minutes. Then come back to Chrome (pause Spotify first) and tap Mark.
  3. 3 Locked: tap 3 Locked, then press the power button with this page in front. Wait 3 minutes, unlock and tap Mark.
  4. 4a Spotify + loop: tap it (the quiet loop starts; you should see it in the notification shade). Open Spotify and play a song for 3 minutes, come back, tap Mark. Spotify will probably pause the loop. That is a result, so don't restart it while you're in Spotify.
  5. 4b Locked + loop: tap it (the loop restarts), lock the screen for 3 minutes, unlock, tap Mark.
  6. Tap Done, then Share log (or Copy log) and send it back.

The timer in the status box shows how long the current phase has run. The Keep screen on option holds a wake lock, which spoils the lock-screen steps, so leave it off unless you're testing a walk with the screen on (task 007).
